# Flashcards ENEM 2026 - Landing Page

Landing Page de alta conversão para venda de Flashcards ENEM 2026.

## 🚀 Como Rodar Localmente

1. Tenha o Node.js instalado.
2. Execute no terminal:
   ```bash
   node server.js
   ```
3. Acesse no navegador:
   `http://localhost:3000`

## 🛠️ Tecnologias Utilizadas
- HTML5 / Tailwind CSS
- Vanilla JavaScript
- Meta Pixel (`1672566531254587`)
- Utmify & Preservação Automática de UTMs
- Checkout Cakto Integrado
